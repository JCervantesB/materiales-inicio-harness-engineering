# Respuestas: el código de `tareas` corregido

Estos archivos muestran el código del starter **ya corregido**, para revisar el
trabajo del alumno y para las demos. Cada uno indica qué problema resuelve.

| Problema sembrado | Lección | Corrección en |
|---|---|---|
| `any` en `parseTarea` | 2.1 | `services-tareas.fixed.ts` (se elimina `parseTarea`) |
| Errores de tipos en `editarTarea`/`marcarCompletada` | 1.3 | `services-tareas.fixed.ts` + `db-tareas.fixed.ts` |
| Import arquitectónico en `ContadorTareas` | 2.2 | `contador-tareas.fixed.tsx` |
| Contador muestra `total` en vez de `completadas` | 7.1 | `contador-tareas.fixed.tsx` |
| `diasRestantes` con `floor` | 4.1 | `fechas.fixed.ts` |

> Las funcionalidades pendientes "Editar", "Completar" y "Filtrar por etiqueta"
> se implementan como ejercicios del curso (lecciones 1.1, 8.2 y 8.3). Aquí solo
> se incluye la capa de datos/servicio que las soporta.
