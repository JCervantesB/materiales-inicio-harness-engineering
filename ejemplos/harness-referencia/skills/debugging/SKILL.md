# Debugging

## Cuándo usarla

Cuando una verificación o un usuario reporta un comportamiento incorrecto.

## Pasos

1. Reproducir el error (prueba o navegador).
2. Obtener evidencia: captura, consola, red, traza.
3. Clasificar el error: visual, funcional o de entorno.
4. Aislar la causa (cambio mínimo).
5. Corregir.
6. Añadir una prueba de regresión.

## Qué significa "terminada"

La corrección verificada y una prueba que impide que vuelva a ocurrir.
