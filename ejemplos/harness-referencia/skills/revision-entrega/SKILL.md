# Revisión previa a entrega

## Cuándo usarla

Inmediatamente antes de dar una tarea por terminada y entregarla.

## Pasos

1. Ejecutar `npm run verificar:todo`.
2. Revisar el `diff` completo.
3. Confirmar que los criterios de aceptación se cumplen.
4. Reunir la evidencia (resultados de pruebas, capturas si aplica).
5. Informar métricas: iteraciones, errores detectados y corregidos.

## Qué significa "terminada"

Evidencia completa de que el cambio cumple los criterios, lista para revisión.
